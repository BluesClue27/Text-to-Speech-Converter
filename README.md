# 🎙️ Text to Speech Converter

A full-stack serverless web app that converts text input into speech using **Amazon Polly**, built with **React**, **AWS Lambda**, and **API Gateway**.

## 🧠 Features

- 🎤 Convert any text into natural-sounding speech
- ☁️ Serverless backend with AWS Lambda
- 🔊 Audio streamed via S3 with pre-signed URLs
- 🌐 CORS-enabled for secure frontend-backend communication

---

## 🧱 Tech Stack

| Frontend     | Backend         | Infra           | AI           |
| ------------ | --------------- | --------------- | ------------ |
| React + Vite | Python (Lambda) | API Gateway, S3 | Amazon Polly |
